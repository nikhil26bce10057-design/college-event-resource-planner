# College Event Resource Planner

## Overview

College Event Resource Planner is a Python command-line application that helps users plan basic resources for a college event.

The application collects event information such as event name, event type, expected attendance, venue capacity, and available volunteers.

It then calculates basic resource requirements and provides planning feedback.

## Features

- Create a new event
- Select different event types
- Validate user input
- Calculate required chairs
- Calculate required volunteers
- Calculate registration desks
- Calculate water bottles
- Check venue capacity
- Check volunteer availability
- Identify additional volunteers required
- View saved events
- Display an event summary

## Event Types

The application supports:

- Seminar
- Workshop
- Cultural Event
- Sports Event
- Conference
