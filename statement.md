# Project Statement

## Project Title

College Event Resource Planner

## Problem Statement

Planning resources for a college event can be difficult when the expected number of attendees, venue capacity, and available volunteers are not considered together.

The College Event Resource Planner is a Python-based command-line application designed to help users estimate basic event resources and identify simple planning issues.

The application takes event information from the user and provides resource calculations and planning feedback.

## Scope

The project focuses on basic resource planning for college events.

The application calculates:

- Required chairs
- Required volunteers
- Required registration desks
- Required water bottles
- Venue suitability
- Volunteer availability

The project does not handle actual bookings, payments, online registration, or real-time inventory.

## Target Users

The intended users are:

- College students organizing events
- Student clubs
- College event coordinators
- Faculty members assisting with small events

## High-Level Features

1. Create a new event
2. Select an event type
3. Enter expected attendance
4. Enter venue capacity
5. Enter available volunteers
6. Calculate required resources
7. Check venue suitability
8. Check volunteer availability
9. View saved events
10. Handle invalid user input
